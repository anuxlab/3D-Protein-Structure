# AI Systems for Predicting Protein 3D Structures

A short documentation set covering the main AI methods for protein structure prediction, the companies and organizations building them, and practical guidance for choosing and interpreting these tools.

## Documentation sequence

| Order | Document | Description |
|---|---|---|
| 1 | [Overview](docs/01-overview.md) | The protein folding problem and core AI concepts |
| 2 | [Major AI Systems](docs/02-major-ai-systems.md) | AlphaFold2/3, RoseTTAFold, ESMFold, OmegaFold, and emerging models |
| 3 | [Companies and Ecosystem](docs/03-companies-ecosystem.md) | Tech giants, AI biotech startups, open-source efforts, and notable Chinese players |
| 4 | [Choosing a Tool](docs/04-choosing-a-tool.md) | Practical selection guidance and example workflows |
| 5 | [Limitations and Interpretation](docs/05-limitations-and-interpretation.md) | Confidence scores, static structures, disorder, and biological caveats |

## Intended audience

Researchers, students, and engineers who want a concise, GitHub-readable introduction to modern AI-based protein structure prediction.

## Scope note

This documentation is an overview, not a benchmark report. Model performance depends on the specific protein, complex, available homology, and evaluation criteria.
